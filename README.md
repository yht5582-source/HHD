# 居家血液透析 (HHD) 處方決策輔助與評估工具 
**Home Hemodialysis (HHD) Prescription Decision Support & Evaluation Tool**

## 📝 專案簡介
這是一個基於純前端技術（HTML/CSS/JavaScript）開發的單頁互動式臨床決策輔助應用程式 (SPA)。本工具旨在協助臨床醫療人員與透析團隊，依據患者的生理數據、生化指標（如電解質、殘餘尿量）、血管通路狀態以及居家照護條件，快速評估並推薦最合適的居家血液透析模式（短時間每日透析 SDHHD 或 夜間長時透析 NHHD），並輔助計算安全、合理的透析處方參數。

## ✨ 核心功能
* **🧠 動態模式推薦演算法**
  * 根據患者的殘餘腎功能、血磷濃度及預期脫水負擔，智慧判定並推薦最適合的透析模式。
* **⚙️ 核心處方參數試算**
  * 自動推算並建議每週透析頻率、單次透析時數。
  * 依據模式特性（如夜間長時透析的低流速安全考量），提供建議的血流速 ($Q_b$) 與 透析液流速 ($Q_d$)。
* **🫀 心血管安全防護 (UFR 監測)**
  * 即時計算超濾率 (Ultrafiltration Rate, UFR，單位: mL/kg/hr)。
  * 內建視覺化紅/黃/綠燈號警示，嚴格把關單次脫水速率，防止心肌頓抑 (Myocardial stunning)。
* **🛡️ 臨床安全與環境檢核**
  * 評估水電環境、感染控制及照護夥伴 (Care Partner) 條件。
  * 若為高風險血管通路（如雙腔導管）且無照護者支援，系統將主動警示暫緩居家透析。
* **📋 處方摘要快速匯出**
  * 支援「一鍵複製」完整的評估結果與處方設定，便於快速貼入電子病歷 (EMR) 系統或與團隊分享。

## 💡 臨床參考依據
本工具之參數邏輯與設計參酌國際居家血液透析常規（包含法國與美國的 HHD 模式），涵蓋：
* **短時間每日透析 (Short Daily HHD)**：高頻率 (5-7次/週)、短時間 (2-3小時/次)，搭配適當流速。
* **夜間長時透析 (Nocturnal HHD)**：利用睡眠時間進行 (6-8小時/次)、極低超濾率與低血流速，著重深層溶質清除與心血管保護。
