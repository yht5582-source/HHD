# 居家血液透析適合度與處方決策 v2.4.0

網址：https://yht5582-source.github.io/HHD/

2026-11-01 更新。純 HTML/CSS/JavaScript，無外部套件、後端、分析追蹤或自動儲存。所有個案資料只在頁面記憶體運算。

## 使用流程

1. 預設「尚未開始透析：初始處方規劃」；不需要既有 spKt/V 或實測 K。已在透析時可切換到實測 K 校正。輸入成人體位、預估／實際每週淨 UF、血鉀、血磷、血壓、臨床穩定性與通路。
2. 確認知情意願、訓練、理解／操作能力、無菌技術、支持計畫、居家水電空間、應變、追蹤／備援及費用負擔。未知項目不視為通過；年齡、導管或缺少家屬本身不直接排除。
3. 提供可用日／夜時段、每週最多次數、單次可用時數及個別 UFR 規劃上限。初始規劃以各模式預計 Qb／Qd 與透析器 KoA 自動估算 K；治療後才輸入相同設備設定下的實測 K。不能把 Qb 或 Qd 直接當成 K。
4. 提供量測 V 或用 Watson 估算。殘腎不明時不計入 Kru；可填量測的未按體表面積標準化 Kru，或以定時尿液資料計算。
5. 比較傳統居家、短每日、長時日間與夜間長時模式。系統在時段限制內提出調整，列出基準與調整後 StdKt/V、尖峰 UFR 及改善方案。未完成居家條件的處方只能作条件式規劃。
6. 用複製或列印／另存 PDF 輸出摘要。

## 數值與限制

- Watson 男性 V（L）= 2.447 − 0.09516×年齡 + 0.1074×身高(cm) + 0.3362×體重(kg)；女性 = −2.097 + 0.1069×身高 + 0.2466×體重。
- 規劃 spKt/V = K×t/V（t 分鐘，V mL）；eKt/V = spKt/V×t/(t+Tp)；Tp 依通路為 AV 30.7 或導管 18.5 分鐘（見 v2.2）。
- S = [10080×(1−exp(−eKt/V))/t] / [(1−exp(−eKt/V))/eKt/V + 10080/(N×t) − 1]。
- 總 StdKt/V = S/[1−(0.74/N)×(每週 UF/V)] + Kru×10080/V；UF 與 V 均用 mL。
- 非每週三次療程：總 StdKt/V 目標 ≥2.3、最低實際輸送量 ≥2.1；每週三次且無／不計殘腎者另依單次 spKt/V 目標 ≥1.4／最低 ≥1.2。正的量測 Kru 可進行個別總量規劃。
- UF 未測 Kru 不補入猜測值。增加頻率時重新估算單次 UF；預設最長間隔 3 次/週72h、4–6 次48h、7次24h，體液均勻累積近似。可用最大單次 UF 覆蓋此假設，但更改频率後須重新確認。
- K±20% 僅為敏感度情境，不是統計信賴區間。三次／週含長間隔、不規則排程、特殊體型及低透析液量設備須正式動力學核對。
- Kt/V 達標不代表整體治療充分。UFR 10、13 是風險提示，不能保證安全。Qb、Qd、透析液電解質與抗凝須由團隊另行設定。
- 此工具不是經驗證的居家適合度評分或自動醫療核准；急性不穩、高鉀、低血壓、通路感染先院內處理。

## 透析前設備規劃（v2.1）

- 分開「尚未開始透析」與「已在透析」。沒有實測 K 仍可規劃；設備參數屬預計處方，不是要求病人提供尚不存在的治療資料。
- 預計連續逆流設備採 Michaels 簡化模型：q=min(Qb,Qd)，Q=max(Qb,Qd)，E=exp[−KoA×(1/q−1/Q)]；理論 K=q×(1−E)/(1−q/Q×E)。相等流量時 K=Qb×KoA/(Qb+KoA)。
- 可輸入已選透析器的廠商尿素 KoA。設備未確定時 KoA=800 mL/min 只作示範情境；80% 清除折減是可調情境假設，非臨床驗證常數。
- 初始 Qb/Qd 預載：傳統300/500、短每日350/500、長時日間250/500、夜間200/300 mL/min，均可改，不代表特定機器或病人的處方核准。
- 沒有完整處理血比容、血液水分率、再循環、凝血、中斷與特殊設備。低透析液量／再循環設備不適用本連續逆流模型。設備未知時不能確認實際足量。
- 每週 UF 在尚未開始透析時填預估需求，依液體攝入、尿量、其他排出與體重趨勢評估；不是要求既有透析紀錄。未開始透析可選「透析低血壓不適用」及「通路尚未建立／待成熟」，分開初始規劃與可實際啟動的條件。
- 新增測試：沒有任何實測 K 的初始個案、模型在 Qb=Qd 的極限、K 流量上限、Qd 改變、廠商 KoA 缺漏、折減範圍、階段切換與清空預設。

[Ward et al. 2012：Qb、Qd、KoA 與尿素清除](https://pmc.ncbi.nlm.nih.gov/articles/PMC3358998/)

## v2.2：通路與反彈校正

AVF/AVG Tp=30.7 分鐘、中央靜脈導管 Tp=18.5 分鐘；未知／預計通路支援雙情境。排序以 AV 情境作較大校正，並顯示 eKt/V 及通路假設。常數反映模型／採血程序，不能推論組織移動快慢或通路優劣。治療後單次劑量核對獨立於候選處方：spKt/V 需實際時間、實際通路與採血適用性確認；eKt/V 直接保留，不再校正。
